## 📖 About

**LUXE** is a modern luxury fashion ecommerce platform built to deliver an elegant, premium shopping experience. Designed with cutting-edge technologies, LUXE caters to fashion enthusiasts and luxury shoppers looking for high-quality apparel and accessories.

Our key differentiators include a meticulously crafted responsive design, a modern and accessible user interface, and a deeply integrated backend that ensures seamless data management and lightning-fast performance across all devices.

---

## 🚀 Features

- ✨ **Product browsing and advanced filtering**: Easily discover products by category, type, and price.
- 🛒 **Shopping cart with real-time updates**: Slide-out cart with instant quantity and total calculations.
- 📱 **Fully responsive design**: Optimized experiences across mobile, tablet, and desktop viewports.
- 🎨 **Modern UI built with TailwindCSS and shadcn/ui**: Clean, accessible, and customizable component library.
- ⚡ **Integrated backend for seamless data management**: Fast and reliable API interactions.
- 🔍 **Detailed product pages with variants and specifications**: View high-resolution images, sizes, and colors.
- 💳 **Checkout functionality**: Streamlined and secure path to purchase.

## 🛠 Tech Stack

| Domain | Technology | Description |
| :--- | :--- | :--- |
| **Frontend** | React 18.2.0 | Core UI library for building reactive user interfaces. |
| **Routing** | React Router 6.16.0 | Declarative routing for client-side navigation. |
| **Styling** | TailwindCSS 3.3.2 | Utility-first CSS framework utilizing custom properties. |
| **UI Components** | shadcn/ui & Framer Motion | Accessible headless components and fluid animations. |
| **State Management** | React Context API | Global state management (e.g., `useCart` hook). |
| **Backend** | Express.js | Fast, unopinionated, minimalist web framework for Node.js. |
| **Database/API** | Horizons Backend | Integrated Horizons backend for products, cart, and orders. |

## 📁 Project Structure

LUXE is structured as a **monorepo**, containing both the frontend client and the backend API logic in a single cohesive repository.
